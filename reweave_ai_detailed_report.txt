REWEAVE AI - DETAILED PLATFORM ARCHITECTURE & LOGIC REPORT
================================================================================

1. EXECUTIVE SUMMARY
--------------------------------------------------------------------------------
ReWeave AI is a state-of-the-art Industrial Circular Intelligence Platform. It acts as a "circular operating system" that links 8 distinct industrial sectors (manufacturers, buyers, recyclers, governments, etc.) into a unified sustainable economy. The platform enables factories to ingest byproduct/waste data, simulate circular recovery via AI, find buyers, and monitor ESG compliance in real-time.

2. TECHNOLOGY STACK
--------------------------------------------------------------------------------
• Framework: Next.js 14 (App Router)
• UI Library: React 18
• Styling: Tailwind CSS v4 (Custom semantic tokens for background, surface, primary, secondary colors)
• Design System: Custom "Industrial Glassmorphism" with holographic gradients, cinematic motion, and CSS-based micro-animations.
• State Management: React Context API (CircularContext)
• Iconography: Google Material Symbols

3. CORE ARCHITECTURE & STATE MANAGEMENT
--------------------------------------------------------------------------------
The entire application logic revolves around a centralized global state manager: `lib/CircularContext.tsx`.

• User State (`user`): Stores the active operator's details (Name, Organization, Role).
• Role-Based Ecosystem: The platform supports 8 distinct roles (Manufacturer, Buyer, Middleman, Recycler, Treatment, NGO, Government, Admin).
• Theming Engine: A utility `getRoleTheme()` dynamically adjusts the color palette based on the user's role (e.g., Neon-Yellow for Buyers, Graphite/Zinc for Manufacturers).
• Global Telemetry: Maintains system-wide metrics like YTD Savings, Avoided Carbon Tons, and Recycled Water Gallons.
• Notification System: A global array of real-time alerts that can be triggered from anywhere and pushed to the top navigation dropdown.

4. PAGE-BY-PAGE LOGIC & WORKFLOWS
--------------------------------------------------------------------------------

A. Authentication & Onboarding (`app/login/page.tsx`)
• Logic: A multi-step interactive wizard. 
• Step 1: Secure Gateway login with facility email/password.
• Step 2: Role Selection. Users explicitly choose one of the 8 network roles.
• Step 3: Node Synchronization. Users input their industry type, facility count, and geolocation.
• Flow: Once completed, `loginUser` updates the global Context and redirects to `/dashboard`.

B. The Neural Dashboard (`app/dashboard/page.tsx`)
• Logic: The central hub. It uses conditional rendering based on `user.role` to ensure a minimal, persona-specific experience.
• For Manufacturers: Displays the "Industrial Data Ingestion" drag-and-drop tool for uploading CSV/PDF waste telemetry. Triggers `ingestWasteStream` in Context.
• For Buyers: Displays the "Procurement Hub" to browse recycled byproduct catalogs and analyze carbon offsets.
• For Middlemen: Displays "Logistics & Transport Corridors" for route optimization.
• Global Elements (Hidden for non-manufacturers): "Circular Flow Intelligence Engine" showing ecosystem efficiency and the "Global Telemetry Bar".

C. Digital Water Twin (`app/dashboard/water-twin/page.tsx`)
• Logic: Simulates a physical water treatment facility digitally.
• UI: Uses HTML5 Canvas / CSS animations to render a pulsing, interactive representation of chemical effluent flow.
• Functionality: Users can monitor live pH, TDS, and Turbidity levels, and trigger "Purification Sequences" which calculate ROI and update global water savings metrics.

D. 3D Innovation Lab (`app/dashboard/innovation-lab/page.tsx`)
• Logic: The core AI product generator. 
• Flow: A manufacturer selects a waste stream (e.g., Textile Sludge). The UI simulates "Neural Synthesis", extracting chemical data (Cellulose, Polymers).
• Output: Recommends 3 high-value secondary products (e.g., Acoustic Panels, Eco-Bricks) complete with profit margins, matching confidence, and required processes.

E. Supply Chain & Logistics (`app/dashboard/supply-chain/page.tsx`)
• Logic: Maps the physical movement of recovered goods. 
• Features: Route optimization algorithms (simulated), freight carrier dispatching, and geospatial smart contracts.

F. Carbon Analytics (`app/dashboard/carbon/page.tsx`)
• Logic: Tracks Scope 1, 2, and 3 emissions.
• Features: Calculates the offset generated by selling waste instead of dumping it. Includes an interface to push "Certified Carbon Credits" to a regional exchange.

G. Expert Network (`app/dashboard/expert-network/page.tsx`)
• Logic: A localized marketplace for environmental consultants, NGOs, and specialized engineers.
• Features: Users can view consultant profiles and click "Request Collaboration", firing off an interactive smart-contract notification.

H. Reports Center (`app/dashboard/reports/page.tsx`)
• Logic: An export hub for regulatory compliance.
• Features: Generates simulated PDF/XLSX downloads for SEC Climate Alignment, Circular Materials Ledgers, and Scope Emission certificates. 

I. Pricing Intelligence (`app/pricing-intelligence/page.tsx`)
• Logic: Enterprise subscription showcase.
• Features: 5 scalable plans (Starter to Enterprise). Includes a dynamic feature comparison matrix, live commodity exchange ticker, and AI usage meters.
• Payment Flow: Clicking "Activate" opens a futuristic Razorpay-style modal. Users select a payment method (UPI/Card), which triggers a simulated backend processing animation before unlocking the platform.

5. DESIGN & UX PRINCIPLES
--------------------------------------------------------------------------------
• Layout: CSS Grid and Flexbox are heavily used to create dashboard widgets that mimic high-end industrial control panels.
• Visuals: We avoided flat design in favor of "Tactile Glassmorphism"—panels have borders, subtle shadows, and blur effects (`backdrop-blur-glass`) to create depth.
• Interaction: Every button has explicit hover states, micro-animations (`hover-lift`, `animate-pulse`), and triggers global success/error notifications to feel responsive and alive.
• Role-Isolation: To keep the interface clean, the platform forces users to select a role at login, hiding irrelevant complex manufacturing data from Buyers or Government officials.
